VibeVoice-based Audio Editing

Local experiment dashboard · MiniCPM-o + VibeVoice hybrid

Side project. The official ICASSP 2027 AEC submission lives at jxzhen/aec-2027-editx-lora (LoRA on stepfun-ai/Step-Audio-EditX). This dashboard tracks the side-project experiment that combines openbmb/MiniCPM-o with microsoft/VibeVoice; it does not affect the official grading chain.

Metric scope. The numbers on this page are reference-signal metrics (SI-SDR / PESQ / STOI / Mel L1 / LSD) computed on one local clip. They are not the official AEC metrics. The official ICASSP 2027 AEC metrics are IFR (instruction fulfilment rate), CR (content retention) and EMR (exact-match rate), produced by the unmodified official evaluator (python -m eval.score). Nothing in that metric space is published here, and no number on this page should be read as an AEC leaderboard score.

What this dashboard does

Reads the JSON outputs produced by the sibling weight repo (jxzhen/vibevoice-based_weight) and lets the author (and anyone running the local experiment) eyeball the numbers in a single page.

  • Audio editing comparison — our MiniCPM-o + VibeVoice hybrid vs AudioEditor (ICASSP 2025), Audit (NeurIPS 2023), InstructSpeech (ICML 2024).
  • ASR comparison — VibeVoice-ASR (7B) vs Whisper large-v3 / turbo, Paraformer-v2.
  • Goal: beat the published reference numbers of AudioEditor (ICASSP 2025) on the reference-signal metrics with a small-model hybrid. The reference numbers are listed in data/summary.json with a per-row Provenance column -- read it before using any of them, because two of the rows carry values that could not be traced to a primary source and are therefore not shown in the metric columns.

3. Observations

  • AudioEditor (ICASSP 2025) reports FD / KL / FAD / IS / CLAP-cosine and MOS — it does not report SI-SDR / PESQ / STOI / Mel L1 / LSD. Any row here that claims AudioEditor numbers on those metrics is marked unverified.
  • The MiniCPM-o + VibeVoice hybrid is meant to combine a small omni-modal LLM with a 7B audio LLM. The exact combined parameter count is not asserted on this page.
  • If summary.json shows our row beating a reference row on any metric, the small-model hybrid hypothesis is supported — but only for rows whose Provenance says the value was actually measured locally.
  • Numbers refresh automatically when you re-run aggregate.py and reload the page.
